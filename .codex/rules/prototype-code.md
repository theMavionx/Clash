# Prototype Code Rules

Prototype code may be rough, hardcoded, and disposable when the goal is learning quickly.

Still required:

- Keep prototypes isolated from production code.
- Include a README with hypothesis, how to run, status, and findings.
- Do not deploy prototype code as production.
- Rewrite successful prototype ideas to production standards before promotion.
