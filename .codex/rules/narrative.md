# Narrative Rules

- Cross-reference new lore against existing lore.
- Mark canon level when adding durable lore: Established, Provisional, or Under Review.
- Keep character voice consistent with existing profiles.
- Document world rules explicitly.
- Keep narrative text localization-ready with named placeholders for variables.
- Keep dialogue lines within UI constraints.
