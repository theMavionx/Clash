# Air Bomb visual frame audit

Generated by `res://prototypes/air-bomb-defense/air_bomb_visual_probe.tscn` at a
square 768x768 viewport. The probe positions projectile visuals for presentation
only; it does not simulate targeting, homing, impact, damage, or reload authority.

| Frame | Presented state | Expected invariant |
|---|---|---|
| `01_loaded_idle.png` | Supplied PBR albedo on the complete carried payload | Both balloons, bridle, and bomb/barrel are loaded as one assembly |
| `02_flag_applied.png` | Probe flag fitted to the reduced balloons | Full image is centered with preserved aspect ratio at 30% of the canvas; it does not stretch or affect base/support materials |
| `03_payload_detach.png` | Complete payload detached at its shared muzzle | Both balloons, bridle, and bomb leave together; launcher is empty |
| `04_vertical_rise_50.png` | Payload halfway through the canonical 0.34-world-unit vertical launch rise | No horizontal homing is presented during the 21-tick rise |
| `05_vertical_rise_complete.png` | Payload at the top of the canonical 0.34-world-unit / 21-tick rise | Complete 1,272-triangle payload remains rigidly grouped |
| `06_homing_25.png` | Complete payload at 25% of the presentation homing path | Homing begins only after the vertical-rise presentation completes |
| `07_homing_50.png` | Complete payload at 50% of the presentation homing path | Building base transform remains unchanged |
| `08_homing_75.png` | Complete payload at 75% of the presentation homing path | Player flag and payload PBR materials remain bound |
| `09_empty_launcher_reload.png` | Empty launcher at 50% reload presentation | Payload stays hidden until the authoritative ready edge |
| `10_full_payload_reloaded.png` | Complete payload restored after reload and idempotent reset | All payload and base transforms exactly match rest state |

`probe_results.json` records the engine build, measured bounds, exact muzzle
positions, runtime paths, triangle budgets, and pass/fail status for the run.

## Verification results

- Visual probe: PASS on the Godot Compatibility renderer (AMD Radeon Graphics).
- Production visual scale: `0.035`, exactly 30% below the preceding `0.05` presentation;
  gameplay footprint and ranges are unchanged.
- Render-FPS parity: PASS at 10, 20, 30, 60, and 120 FPS. Every corresponding
  frame and the thumbnail produced exactly one unique SHA-256 across all five runs.
- Repository quick gate: PASS after asset integration.
- Local import/capture engine: Godot `4.6.stable.official.89cea1439`.
- Target-version follow-up: reimport and inspect once the documented Godot 4.6.1
  binary is available; the local machine currently provides 4.6.0 stable.
